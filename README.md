# 🚀 Guide d'installation

## 📥 1. Cloner le projet

```bash
git clone <https://github.com/RojoIrina/Projet-Qualimetrie-Smart-Warehouse.git>
cd smart-warehouse
📦 2. Installer les dépendances
npm install
▶️ 3. Lancer le serveur
node index.js

Le serveur démarre localement sur le port configuré dans le projet.

🤝 Flux de travail collaboratif

Afin d’éviter les conflits et de rester synchronisés, chaque membre doit suivre ce workflow :

🔄 Avant de commencer à travailler
git pull origin main

Permet de récupérer les dernières modifications de l’équipe.

💾 Après les modifications
git add .
git commit -m "Description des modifications"
git push origin main
